# Frontend Assignment - Showcase Page

## Overview
A responsive and interactive product showcase page built according to design specifications.

## Tech Stack
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Lucide React
- next/image

## Setup Steps

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Start production server:**
   ```bash
   npm start
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
